## Atomistic Scale Simulations

Guided coursework project in PHYS4061 (Project A: Atomistic scale simulations) for atomistic-scale materials simulation.
    

Part 1: Implemented a modular C program to generate SC, BCC, FCC, and diamond cubic crystals with periodic boundary conditions, outputting XYZ files for visualisation in VMD.

Part 2: Computed primitive and reciprocal lattice vectors from lattice constants, and built neighbor lists with PBC to verify first- and second-nearest-neighbor distances.

Part 3: Implemented Lennard-Jones and Stillinger-Weber potential energy calculations with minimum-image convention, validated against theoretical equilibrium energies.
